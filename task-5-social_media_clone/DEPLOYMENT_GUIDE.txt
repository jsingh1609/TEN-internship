## 🔧 FRONTEND SETUP (DETAILED)

Since you're working in a container environment, here's the complete frontend setup:

```bash
cd /home/claude/vibegram-instagram-clone/frontend

# 1. Install dependencies
npm install react react-dom lucide-react
npm install -D vite @vitejs/plugin-react

# 2. Create vite.config.js
cat > vite.config.js << 'VITECONFIG'
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    port: 3000,
    host: true
  }
})
VITECONFIG

# 3. Create index.html
cat > index.html << 'INDEXHTML'
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vibegram - Instagram Clone</title>
    <script src="https://cdn.tailwindcss.com"></script>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.jsx"></script>
  </body>
</html>
INDEXHTML

# 4. Create main.jsx
cat > src/main.jsx << 'MAINJSX'
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App'

ReactDOM.createRoot(document.getElementById('root')).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
)
MAINJSX

# 5. Update package.json scripts
npm pkg set scripts.dev="vite"
npm pkg set scripts.build="vite build"
npm pkg set scripts.preview="vite preview"

# 6. Start development server
npm run dev
```

## 🔌 API ENDPOINTS REFERENCE

Base URL: http://localhost:8000/api/

### Users
GET    /users/              - List all users
GET    /users/{id}/         - Get user details

POST   /comments/           - Create comment

### Stories

### Messages
GET    /messages/           - List messages

## 🐛 TROUBLESHOOTING

### Backend Issues

**Port 8000 already in use:**
```bash
lsof -ti:8000 | xargs kill -9
# or
pkill -f "manage.py runserver"
```

**Database locked:**
```bash
python manage.py migrate --run-syncdb
```

**CORS errors:**
Check that `django-cors-headers` is in INSTALLED_APPS and MIDDLEWARE

### Frontend Issues

**npm install fails:**
```bash
rm -rf node_modules package-lock.json
npm cache clean --force
npm install
```

**Port 3000 in use:**
Change port in vite.config.js

**Tailwind not loading:**
Check that CDN link is in index.html
