# Skill Core — Topographical Tech Skill Recommendations

Skill Core is a high-performance recommendation engine designed for modern engineers to discover adjacent technologies and expand their technical depth.

## ✨ Features

- **Cinematic Initialization**: A custom-built loading sequence featuring a central 8-point star and dual 6-point stars, symbolizing technical synergy and core processing.
- **Topographical Interface**: A premium dark-mode UI with a "Topographical Engine" aesthetic, utilizing 3D perspective layers and grain filters for a state-of-the-art feel.
- **Smart Skill Stack**: Select technologies you already know or love to generate an "Event Horizon" of recommendations.
- **Adaptive Discovery**: Real-time filtering and search across 60+ industry-standard tech skills.
- **Session Intelligence**: The system intelligently manages page state, ensuring the loading experience is triggered on every fresh session or manual refresh for maximum immersion.

## 🚀 Getting Started

Simply open the project in any modern web browser:

1. Launch `index.html` to begin the system initialization.
2. Once the "Skill Core" is ready, you will be transitioned to the main dashboard.
3. Click on skill cards to add them to your stack and see related technologies surface in the recommendation grid.

## 🛠️ Technology Stack

- **HTML5**: Semantic structure and SVG-based custom iconography.
- **Vanilla CSS**: Advanced layout using Flexbox, Grid, and 3D transforms for the topographical effects.
- **JavaScript**: Custom logic for skill filtering, recommendation weighting, and session state management.

## 📂 Project Structure

- `index.html`: The cinematic entry point and loading sequence.
- `home.html`: The main dashboard and recommendation interface.
- `style.css`: Core design system and animations.
- `app.js`: Application logic and skill database.
